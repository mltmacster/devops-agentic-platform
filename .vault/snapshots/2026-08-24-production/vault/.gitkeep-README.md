# VAULT — Project Knowledge Repository

**PROTECTION NOTICE**: This directory is the project's official knowledge repository.
Agents and automation MUST NOT delete, remove, or auto-purge files in this directory.

## Directory Structure

```
.vault/
├── VAULT_CONFIG.yaml            # Schema definitions (READ-ONLY)
├── VAULT_COORDINATOR.yaml       # Cross-cutting coordination rules (READ-ONLY)
├── VAULT_DEPLOYMENT.yaml        # Future development roadmap & pipeline (READ-ONLY)
├── LIFECYCLE_PROTOCOL.md        # Artifact lifecycle rules (READ-ONLY)
├── VAULT_OVERVIEW.md            # Current architecture state
├── SNAPSHOT_LOG.md              # All snapshots tracked here
├── SOLUTIONS.md                 # Documented troubleshooting solutions (15 solutions)
│
├── archive/                     # Deprecated & Retired artifacts with lifecycle docs
├── snapshots/                   # UI/code state snapshots for preview & regression testing
│   └── 2026-08-21/              # Today's snapshots
│       └── architecture-state.md  # Architecture snapshot
├── designs/                     # Design documents, ADRs, Mermaid diagrams
├── scripts/                     # Reusable troubleshooting & automation scripts
│   ├── validate_vault.sh       # Validate Vault YAML configs
│   └── run_all_tests.sh        # Run all tests with proper env vars
├── docs/                        # Technical documentation, API references
└── metrics/                     # Performance metrics, benchmark reports
```

## Lifecycle Summary (Quick Reference)

| Stage | Description | Action Required |
|-------|-------------|-----------------|
| **Created** | Artifact created and validated | Add to SNAPSHOT_LOG.md |
| **In Use** | Actively referenced in code/docs | Track usage & metrics |
| **Declined** | Outdated but still referenced | Update with migration path |
| **Retired** | Fully retired, preserved for reference | Create RETIREMENT.md in archive/ |
| **Archived** | Moved to long-term storage | Update access level |

## Quick Commands for Vault Maintenance

```bash
# Run all tests with proper env vars
export TESTING=1 && python -m pytest tests/ -v

# Validate Vault YAML configs
python .vault/scripts/validate_vault.sh

# Add a new snapshot (run after major changes)
mkdir -p .vault/snapshots/YYYY-MM-DD-HH/MM/
# Add snapshot documentation here

# Archive a deprecated component
mkdir -p .vault/archive/YYYY-MM-DD_<component>/
cp path/to/old-code/ .vault/archive/YYYY-MM-DD_<component>/
# Create RETIREMENT.md in the archive folder
```

## Agent Behavior Rules (NON-NEGOTIABLE)

1. **NEVER delete files** in `.vault/` without explicit human approval
2. **ALWAYS create snapshots** before major code changes (> 50 lines)
3. **Document all fixes** in `.vault/SOLUTIONS.md` with verification steps
4. **Never auto-purge** old content — nothing is automatically deleted
5. **All changes must be traced** back to a specific session/commit
